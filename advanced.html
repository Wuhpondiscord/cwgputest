Advanced WebGPU experiments

Browser-local performance and portable checkpoint tests. Nothing is sent to a server. Export/import is manual.

Configuration

Each trial validates the complete GPU output. Workload: 1.0 added per element per dispatch.

1. Dispatch batching and synchronized readback

Same shader, inputs, dispatch count, and final validation; compare separate queue submissions, one batched submission, and intermediate readback after every dispatch.

2. Checkpoint chunk scaling

Compare 1, 4, 16, and 64 chunks for the same buffer size. Each snapshot is restored and checked.

3. Larger state scaling

Checkpoint 65,536, 131,072, 262,144, and 500,000 elements (256 KiB to approximately 1.91 MiB).

4. Checkpoint frequency

Compare no intermediate checkpoint, every 16, every 4, and every dispatch. Snapshots are read to CPU and discarded, while GPU execution continues.

5. Portable cross-browser checkpoint

Export a validated, versioned checkpoint with raw float32 state and a SHA-256 digest; transfer the file to a second browser or device and import it to restore into a new GPUBuffer and verify the results.

Manual file transfer only. This captures buffer contents and progress, not complete shader pipelines or arbitrary live execution.
